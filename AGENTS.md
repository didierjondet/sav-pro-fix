- Legal identity (company, address, contact e-mail) lives only in `src/lib/legalInfo.ts`; legal pages and contact use it — single source avoids divergent mentions.
- Contact form posts to the `contact-form` edge function, whose recipient is fixed server-side — prevents use as an open mail relay.
- Auth/e-mail redirects go through `src/lib/authRedirect.ts` (Fixway domains only) — never send users to a Lovable host.
- Controller-sheet identification is generated locally with bwip-js using the SAV print Code 128 options and case number — keeps scanning compatible without a network dependency.
- Intake print destinations are selected by getSAVPrintCopies from the persisted customer_id — creation and reprint share a testable rule independent of customer contact details.
- Smartphone SAV intake (/m/sav/nouveau/:token) needs no login: the phone only deposits device data into a one-time mobile_sav_sessions row via token-checked RPCs/edge functions, and the logged-in desktop finishes creation in the usual SAVForm/SAVWizardDialog (prefilled) — phone never reads shop data, all creation rules stay in one place.
- Product family chips (sav_cases.product_family_id → product_families per shop) are suggested by matchFamilyForDevice in src/lib/productFamilies.ts first, then classify-sav-category with the shop's families — one local rule shared by forms, backfill and tests.
- Loaner return QR (/pret/retour/:token) needs no login: anon token-gated RPCs loaner_return_open/submit only touch that loan — the restitution sheet stays in the shop, so the printed token is the credential.
- Activation questionnaire answers live in onboarding_feedback (kind signup|blocker); which prompt shows is decided by pickActivationPrompt in src/lib/activationFeedback.ts — one testable rule, read back per shop in Super Admin via get_activation_funnel.
- Discovery mode: sample rows carry `is_demo` and are created/erased only by RPCs `seed_demo_shop`/`exit_demo_mode`; `shops.demo_mode` hides the inactivity policy dialog — one reversible switch, real data never touched.
- Shop names are unique by `shop_name_key` (case/accents/spaces ignored, placeholder « Mon magasin » exempt); client mirror in `src/lib/shopName.ts` — DB index is the final guard.
